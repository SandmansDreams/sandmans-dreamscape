# What is SpaceGame?

Space game is a little game about building a spaceship and fighting other spaceships while traveling the galaxy. You can build your own ship, including its power, thrust, and weapons, and fly out into the vast galaxy.

## Tech
This game uses the SvelteKit framework as a backbone (since it is on my website) and [[WebGPU]] (the successor to WebGL) in order to reduce render times and physics calculations.
